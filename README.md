# 🐢 The Desert Tortoise on Avalanche C-Chain
*Automated On-Chain Vending Machine & Community Follower Portal*

## Overview
**The Desert Tortoise** is a decentralized public-good initiative built on the **Avalanche C-Chain**, combining wildlife conservation advocacy with low-cost, high-speed automated token distribution. The protocol operates completely autonomously 24/7, providing instant token acquisition and verified community rewards while routing a portion of transactions to conservation foundations.

## Core Features
* **Automated Token Vending (`buyTokens`):** Instant native-currency-to-token purchases with built-in split logic (directing funds securely to operational maintenance and charity foundations).
* **Sybil-Resistant Claim Portal (`claimFreeTokens`):** Secure cryptographic verification (`validClaimCodes`) to reward verified community supporters and followers safely.
* **Avalanche C-Chain Optimized:** Engineered for maximum efficiency, sub-second finality, and low gas fees on Avalanche.
